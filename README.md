# CleanEase - A Platform for Finding Reliable Cleaning Professionals 🧼

## Overview

CleanEase is a web and mobile platform built using the **MERN Stack (MongoDB, Express.js, React, Node.js)** to connect users with trusted cleaning professionals. The platform allows users to **search, filter, and book** specialized cleaning services while enabling professionals to manage appointments and build their reputation.

## Features

### 🌍 User Interface

- **🛒 Service Booking System**: Users can schedule cleaning services, specify details, and choose the number of workers needed.
- **🔎 Search & Filter**: Users can filter available professionals based on **location and ratings**.
- **👤 Profile Management**: Users and workers have individual profiles with relevant information.
- **📱 Responsive Design**: The interface is optimized for both web and mobile.

### 👨‍🔧 Worker Dashboard

- **📅 Appointment Management**: View scheduled cleaning jobs and update availability.
- **⭐ Reputation System**: Workers receive ratings and feedback from clients.

### 🛠️ Admin Panel

- **✅ Quality Control**: Admins oversee worker credentials and service quality.
- **📩 Customer Support**: Manage disputes and client reports via email.
- **📊 Analytics & Reports**: View weekly/monthly earnings and appointments in graphical format.

### ✉️ Email Integration with Nodemailer

- Users and Workers receive **📧 email confirmations** upon successful booking.
- Admins handle customer support queries via **email-based dispute resolution**.

## 🛠️ Tech Stack

- **🖥️ Frontend**: React.js  
- **⚡ Backend**: Node.js & Express.js  
- **🗄️ Database**: MongoDB  
- **🔐 Authentication**: JWT (JSON Web Tokens)  
- **📩 Email Service**: Nodemailer
